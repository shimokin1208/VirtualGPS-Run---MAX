# 路线编辑器（中心光标选点 / 不自动闭环 / 自动保存）

本文描述 1.2.0 起「路线编辑」的行为契约，便于手工回归测试。

## 0. 布局约定（1.2.0 重排）

常驻元素只有三处，其余一律折叠，保证地图中心不被遮挡：

| 位置 | 元素 | 默认状态 |
| --- | --- | --- |
| 左上 | 状态胶囊 | 一行摘要，详情收起（点击展开） |
| 右上 | 地图工具菜单 | 一个按钮，点开才有菜单项 |
| 底部 | 操作坞 | 收起：概览 + 选点确认 + 主按钮 |

> **为什么必须这么改**：1.1.0 的底部是「选点面板 + 路线卡片 + 配速卡片 + 按钮行」竖着叠加，合计约
> 450–500dp。Compose 按声明顺序绘制，底部这一列会直接画在屏幕中心的十字光标之上；定位 FAB 声明在
> 卡片列之前，又用 `offset(-300dp)` 顶进卡片区，于是被整块压住。表现就是「光标没显示」「定位按钮不见了」，
> 功能代码其实没坏。现在中心区域留空，定位按钮改为操作坞内的常驻控件。

## 1. 选点流程

1. 进入应用后默认处于**选点模式**，地图中央显示十字光标（位置固定，不随地图移动）。
   光标绘制与 1.1.0 一致：72dp、半透明蓝底 + 白色十字 + 蓝色中心点。
2. 拖动 / 缩放地图时，光标指向的坐标实时变化，操作坞显示：
   - `预选坐标（GCJ-02）` 与 `39.90420, 116.40740`
   - 标题里的 `第 N 个点`
3. 点 **确认落点** 才会把该坐标写入路线；写入后光标仍在中心，可继续选下一个点。
4. 点 **取消** 退出选点模式（光标隐藏，避免误落点）。
5. 点操作坞的 **选点** 图标按钮（图钉）重新进入选点模式：进入时立刻刷新预选坐标，且已有路线时
   地图会自动回到最后一个点（与 1.1.0 的「重新选点」一致）。
6. 拖动地图时会自动收起展开的设置区，确保中心光标始终可见。

已确认的点显示为带颜色和大小的圆点，与中心的十字光标（未确认预选位置）形状完全不同：

| 类型 | 颜色 | 直径 |
|---|---|---|
| 起点 | 绿 `#2EAD65` | 30dp |
| 途经点 | 蓝 `#1E88E5` | 18dp |
| 终点 | 红 `#E04F5F` | 26dp |

## 2. 闭环

- **不存在**「新点距起点小于某距离就自动闭环」的行为。无论新点离起点多近，都只是追加一个途经点。
- 闭环只有一个入口：展开操作坞后点 **闭环** 按钮（要求 ≥3 个点且尚未闭环）。
- 闭环后再次追加点位会自动解除闭环，并剔除末尾与起点重合的重复点。

## 3. 自动保存与恢复

- 每次变更（落点 / 删除 / 闭环 / 改名 / 清空）都会立即写入
  `SharedPreferences("route_editor")`，键 `saved_route`。
- 存储格式见 `RouteCodec`：版本化文本，包含**完整点位列表**、顺序、类型、路线名与闭环标记。
- 应用重启后自动恢复上次路线，并提示「已恢复上次路线：N 个点」。
- **清除** 会先保存一份内存快照，之后可用 **恢复上次路线**（路线为空时显示在展开区）撤回。

## 4. 运行状态

| 操作 | 行为 |
|---|---|
| 开始 | 需要 ≥2 个点 + 已授权模拟位置；重复点击不会重复启动服务 |
| 暂停 | 服务停止出点，轨迹时间冻结；UI 显示「已暂停」 |
| 继续 | 丢弃暂停期间的时间差，从原位置继续，不会瞬移 |
| 停止 | 结束前台服务并广播终态；路线保留 |
| 完成 | 非闭环路线到达终点后自动结束并归零速度 |

开始跑步后操作坞会自动收起详情；运行中顶部显示进度条与当前配速。

## 5. 快速定位当前地址

1. 操作坞常驻的**定位按钮**（准星图标）或右上角菜单里的「定位到我的位置」；
   （1.1.0 里这个按钮是存在的，只是被底部卡片列盖住了，1.2.0 改为操作坞内常驻控件）
2. 取位顺序：先看各 provider 的 `lastKnownLocation`（60 秒内视为新鲜），不够新则同时向
   GPS / NETWORK 各要一次单点定位，谁先回用谁，最长等 6 秒；
3. 优先使用非模拟定位；本应用运行中 GPS provider 已被 mock，此时退回最后一手可得的位置；
4. 结果按 WGS-84 → GCJ-02 换算后飞到该点（缩放 17.5），800ms 动画结束后把中心光标同步过去，
   选点模式下可直接「确认落点」；
5. 反查地址（`Geocoder`）成功时，状态胶囊详情里出现 `当前地址`，同时弹出 Toast。
6. 失败分流：未授权定位权限 → 应用设置；系统定位关闭 → 系统定位设置；其余 → 提示稍后重试。

## 6. 状态详情

状态胶囊展开后：

1. `系统定位`：模拟位置是否已授权 + GPS 开关状态
2. `模拟位置`：当前输出的 WGS-84 坐标（无则显示「尚无」）
3. `地图路线`：点位数 + 单程/闭环
4. `当前地址`：只在成功反查后出现

## 7. 异常与兼容

- 无网络时不额外弹提示条，改为在状态胶囊摘要里显示「无网络」，选点仍可用（依赖已缓存瓦片）。
- 地图初始化 / 切换底图失败会弹出提示，不会崩溃。
- `android.location.provider.ProviderProperties` 仅 API 31+ 存在，低版本走已废弃的 int 重载，
  `minSdk 26` 设备不会因 `NoClassDefFoundError` 崩溃。
- 屏幕旋转：路线状态在 ViewModel 中，不丢失；光标由全屏 `Box` + `contentAlignment = Center` 重新居中。
- 展开区限制 `heightIn(max = 236.dp)` 且可滚动，小屏展开也不会挤掉地图。

## 8. 已移除（1.2.0）

- 首次启动的「仅用于测试」须知弹窗与确认门禁（`TestOnlyNoticeDialog`），应用打开即进入地图；
- 右上角「测试模式」`FilterChip` 与地图水印；
- 状态栏合规说明行与通知栏 `[测试]` 前缀；
- 整个 `compliance` 包（`ComplianceStore` / `TestLabelPolicy`）与其单元测试 `TestLabelPolicyTest`。

因此 `SharedPreferences("compliance")` 里的历史键值不再被读取，可以忽略。
